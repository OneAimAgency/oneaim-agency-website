# OneAim Agency — Logo Assets

Mark: **Continuous climb** — three rising rules run up into the A's left stem.
Typeface: **Jost 300**, all-caps, letter-spacing 0.2em.

## Colours
| Role | Hex |
|---|---|
| Onyx (base) | `#0D0D11` |
| Violet (accent, on dark) | `#8B45FF` |
| Violet (accent, on light) | `#6C22E0` |
| Off-white | `#F7F6F4` |
| Ink (on light) | `#101014` |

## Files

**svg/** — scalable, no font needed (pure geometry, the mark only)
- `mark-on-dark.svg` — white + violet, for dark backgrounds
- `mark-on-light.svg` — ink + violet, for light backgrounds
- `mark-mono-black.svg` / `mark-mono-white.svg` — one-colour, for print, embroidery, engraving
- `mark-small-cut-*.svg` — heavier cut, crossbar dropped. **Use below ~20px.**

**png/**
- `avatar-1080-dark.png` — Instagram / TikTok profile picture
- `avatar-1080-violet.png` — alternate, brand colour block
- `avatar-1080-light.png` — alternate, light
- `lockup-2400-dark.png` / `lockup-2400-light.png` — full wordmark, website header
- `lockup-1080-square-dark.png` / `lockup-1080-square-light.png` — full wordmark, 1080 × 1080 (Instagram post / square placements)
- `lockup-1080-wide-dark.png` / `lockup-1080-wide-light.png` — full wordmark, 1080 × 360 strip
- `icon-512-dark.png` / `icon-512-violet.png` — favicon, app icon
- `banner-1500x500-dark.png` — X / LinkedIn / YouTube header

## Where to use what
- **Instagram & TikTok profile:** `avatar-1080-dark.png`. The full wordmark is too wide to read in a circular avatar — the mark alone is the correct choice there.
- **Website header:** `lockup-2400-dark.png` or the light version. Scale down; never scale up.
- **Favicon:** `icon-512-dark.png`.
- **Anything under 20px:** use the small cut. The fading run-up rules and the crossbar dissolve at tiny sizes.

## Rules
- Keep clear space around the mark equal to the height of the tallest rule.
- Don't recolour the accent, stretch the mark, add effects, or reduce the tracking on the wordmark.
- On photography, use the mono white version.

## Notes
- The SVGs contain the **mark only**, so they're font-independent and safe to hand to any developer or printer.
- The full wordmark lockups are supplied as PNG because the wordmark is live Jost text. To get a vector wordmark, install Jost (free, Google Fonts) and set `ONE AIM` at 0.2em tracking, then convert to outlines.
